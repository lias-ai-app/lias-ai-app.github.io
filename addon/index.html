תוסף LIAS לפיירפוקס

התחברות ל-gov.il דרך פיירפוקס ושיתוף ההתחברות עם LIAS. גרסה 0.4.0.

התקן את התוסף הורד את הקובץ

במק

  1. פותחים את הדף הזה בפיירפוקס ולוחצים "התקן את התוסף".
  2. פיירפוקס שואל אם להוסיף את LIAS Sign-in — לוחצים "הוספה".
  3. אם לא קרה כלום: מורידים את הקובץ, ובפיירפוקס נכנסים ל-about:addons ← גלגל השיניים ← "התקנת תוספת מקובץ".

בטלפון (אנדרואיד)

  1. מתקינים את פיירפוקס מ-Google Play.
  2. מורידים את הקובץ בכפתור "הורד את הקובץ".
  3. בפיירפוקס: הגדרות ← "אודות Firefox" ← מקישים 5 פעמים על הלוגו (פעם אחת בלבד בטלפון).
  4. חוזרים להגדרות ← "התקנת הרחבה מקובץ" ← בוחרים את הקובץ שהורד ← "הוספה".

אחרי ההתקנה

  1. מחברים את התוסף ל-LIAS: בהגדרות LIAS במק, תחת "התחברות", פותחים בפיירפוקס את קישור החיבור או סורקים את הקוד.
  2. עדכונים מגיעים לבד — פיירפוקס בודק אותם מעצמו פעם ביום.

לשליחה למישהו: שלחו את הקישור לדף הזה. אם הוא נפתח בדפדפן אחר, הוא יפנה לפיירפוקס.
